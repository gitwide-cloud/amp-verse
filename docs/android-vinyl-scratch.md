# Android vinyl scratch (Full core 39)

The Full app DJ screen now scratches actual selected local/offline audio, not repeated seeks or a sample. Hold stops the normal renderer, forward/backward hand motion resamples stereo PCM, and release seeks once to the heard position. Original play/pause state is restored; tempo is never changed by scratch. Explicit Pitch/Sync edits survive release. Cue decks retain their own cue gain; A/B retain crossfader/master gain and the existing EQ processor.

Preparation is asynchronous: four eight-second stereo 48 kHz windows, one coalescing Java worker and one native FFmpeg job across controller recreation. A cancelled native job retains its gate and temporary file until native completion and reader release. Cancellation waits at most 500 ms on the worker; a slow native job is quarantined rather than overlapped. Only the scratch session ID is cancelled. Cache decoding never edits source files. Remote/unprepared sources leave existing playback untouched and report what to do. Lite has no decoder and explicitly requires Full; standalone companion transport has no new vinyl RPC/UI in this change.

The window is bounded: sustained hand travel beyond its edge clamps there until release; subsequent normal movement prepares another window. This is not full-song RAM decoding. Touches outside the drawn platter do not pause audio. Touch cancel/navigation releases owned gestures, while focus loss, explicit pause/stop, source replacement and seeks revoke resume. Tokens and source epochs reject stale wheel/decoder callbacks. Auto Mix cannot start during a held/releasing gesture. Scratch AudioTrack is stopped/flushed before normal playback resumes; renderer and main-player pause acknowledgements precede scratch output.

Pure JVM regressions cover forward/reverse actual samples, rate, held silence, heard rather than queued cursor, four independent voices, angular seam/dead zone/geometry, release-state downgrade and native cancellation ownership. `VinylDecoderDeviceTest` generates a 30-second cache-only WAV, decodes a bounded window with Full FFmpeg, renders real reverse PCM, checks source preservation and cancellation recovery. It does not open a microphone, mutate owner queues or play audible output. Full decoder instrumentation requires the Full APK; Lite explicitly skips that decoder fixture. Instrumentation has been added but not executed on a phone. Gradle CI must compile all Android APIs; device latency, audio routing and touch feel still require owner GitHub-build acceptance. No USB install is part of this change.
