# Library organiser

Library > Organise library provides a review-first exact-duplicate scan and consolidation tool. It reads all configured music sources without changing them. SHA-256 over complete file contents defines a confirmed duplicate: different tags, encodings and edits remain separate. The keeper starts with the most prepared copy, preferring manual edits and saved cues; each duplicate group allows a different choice.

Choose a separate empty destination, review the keeper selections and proposed moves, then explicitly apply. The destination preserves a Library/Sources folder tree rather than flattening colliding filenames. Background copy/checksum verification, preparation publication, playlist remapping and catalog validation finish before originals are removed. Manual cue or source changes detected after the preview prevent the affected original from being removed. Extra duplicates and their preparation remain untouched. Other devices must stop using the source folders during the move. Local playback, analysis, stem jobs and Lab block applying the move.

Regular playlist order and duplicate entries are preserved while paths change. Smart Playlist folder sources, song restrictions, exclusions, preferences and recognition assignments are remapped. An eligible duplicate stored under a different keeper folder receives an explicit mapped reference so it remains eligible. Previously unavailable imported sources remain unavailable. Conflicting manual preparations are not silently merged: all source preparations are retained in the recovery plan and duplicate originals. Existing local prepared stems are archived and restored at the new path without rerunning separation.

The destination ampdj/consolidation.ampdb stores the original plan and a compact progress/report record. Cancel retains completed destination files and unmoved originals. Resume previous consolidation loads that recorded plan after an interruption; changed keeper selections or newer destination playlist edits require review instead of being overwritten. The tool does not delete duplicate copies or remove old metadata directories. Use consolidated library explicitly changes the app's music root after completion.

Verified with fixture libraries: identical-content duplicates, unique same-name songs across sources, retained manual cues, Smart/regular playlist remapping, source/metadata changes, nonempty destination rejection, cancellation and resumed work. No live user-library migration is performed during these tests.
