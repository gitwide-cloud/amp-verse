# Auto DJ transition styles

Open DJ / Transition options. Variety rotates enabled techniques at the saved frequency (every 2–12 mixes, default 4). Each technique has an independent switch: Scratch, Stutter, Tape brake, Filter sweep, Bass swap and Beatmatch. Clean fade bypasses effects. Your crossfade time is a separate saved setting.

Scratch plays a short outgoing jog phrase. Stutter repeats a short outgoing segment; Tape brake slows its tail; Filter sweep closes its low-pass. Bass swap performs a staged two-deck EQ blend over the saved crossfade duration: incoming highs enter first, bass exchanges around the midpoint, then mids blend. Cuts are relative to each deck's existing EQ; both decks' original settings return after completion or cancellation. These temporary effects release their controls when a handoff finishes, automation stops, or the jog wheel is taken manually. Tempo matching uses the existing +/-16% pitch range and prepared BPM; beat phase and key lock remain manual. Saved cues and source audio are unchanged.

The supplied mixing-video transcript is a reference for further techniques: phrase-aligned EQ mixing, tightening buildup loops, and vocal/instrument stem handoffs. Those are not implied by the existing Stutter or Bass swap switches. In particular, Bass swap follows fade progress, not a detected musical phrase, and Stutter is a short fixed repeat rather than a quantized tightening loop. No echo/reverb or automatic vocal mashup is added by these presets.

These are selectable performance presets rather than a self-training model. Android can control them through AMP Remote; local phone playback does not add reverse-audio scratching or an analysis engine. See DJ_REQUESTS.md for requests and PORTABLE_DATABASE.md for local file storage.
