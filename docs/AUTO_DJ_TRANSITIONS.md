# Auto DJ transition styles

Open DJ / Transition options. Variety rotates enabled techniques at the saved frequency (every 2–12 mixes, default 4). Each technique has an independent switch: Scratch, Stutter, Tape brake, Filter sweep, Bass swap, Beatmatch, Loop buildup and Stem handoff. The two new techniques start switched off; enable them individually. Clean fade bypasses effects. Your crossfade time is a separate saved setting.

Scratch plays a short outgoing jog phrase. Stutter repeats a short outgoing segment; Tape brake slows its tail; Filter sweep closes its low-pass. Bass swap performs a staged two-deck EQ blend over the saved crossfade duration: incoming highs enter first, bass exchanges around the midpoint, then mids blend. Cuts are relative to each deck's existing EQ; both decks' original settings return after completion or cancellation. These temporary effects release their controls when a handoff finishes, automation stops, or the jog wheel is taken manually. Tempo matching uses the existing +/-16% pitch range and prepared BPM; beat phase and key lock remain manual. Saved cues and source audio are unchanged.

Loop buildup captures four beats of the outgoing audio, then halves the captured loop down to a quarter beat as the mix completes. It requires a saved BPM, at least six beats of crossfade time, and enough outgoing audio to capture the loop. Its lengths follow the current pitched BPM; the start is not beat-grid or phrase quantized. It uses a clean fade when those requirements are missing. Loop resizing reuses the existing audio buffer. It never changes saved cue/loop metadata or extends your selected mix duration.

Stem handoff requires both decks to have their prepared three-part stems loaded. It removes the outgoing vocal, introduces the incoming vocal before its instruments, and exchanges drums around the middle. All changes multiply the existing stem gains, so an already-muted part remains muted. After the mix or cancellation, the previous gains return. Touching a stem knob cancels the temporary effect and applies your manual setting. Without both prepared stem sets it uses a clean fade; separation is never started on the audio thread.

Research references: [Crossfader's looping guide](https://wearecrossfader.co.uk/blog/dj-looping-guide/) explains shortening loops for buildup and distinguishes ordinary loops from slip rolls. [Crossfader's performance breakdown](https://wearecrossfader.co.uk/blog/pro-dj-methods-explained/) covers phrase timing, fader cuts and loop tightening. [Serato's stems guide](https://support.serato.com/hc/en-us/articles/5700921209615-Using-Stems) illustrates isolating separated parts. The supplied DJ Blakey video/transcript additionally demonstrates tempo ramps, slip hot-cue routines and drum swaps. AMP's implementations use its existing three-part preparation; they do not copy another application's code.

Still outside these presets: echo/reverb tails, slip-mode cue drumming, automatic phrase detection, and wide-tempo ramps with key lock. Bass swap follows fade progress, not a detected phrase; Loop buildup is not a slip roll. Prepared cue and song selection remain essential to a musical result.

These are selectable performance presets rather than a self-training model. Android can control them through AMP Remote; local phone playback does not add reverse-audio scratching or an analysis engine. See DJ_REQUESTS.md for requests and PORTABLE_DATABASE.md for local file storage.
