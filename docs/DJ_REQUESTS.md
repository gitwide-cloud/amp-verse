# Live song requests and transition techniques

Fresh installs start with a single **Demo** playlist. It contains no supplied songs or private event lists. Existing saved playlists remain intact on upgrade.

Desktop DJ / Transition options offers six independent technique switches: Scratch, Stutter, Tape brake, Filter sweep, Bass swap and Beatmatch. Variety rotates the enabled techniques at the saved frequency; Clean fade bypasses effects. The beatmatch technique uses prepared BPM and the deck's existing tempo sync range; it is tempo matching, not a new beat-phase or key-lock algorithm. These are deterministic performance presets, not a trained or self-learning model. Mix time remains independently adjustable.

Right-click a song in the DJ Library to request it within 1–5 songs. Load a Smart Playlist first. Requests join that live session's candidate pool, receive priority over ordinary selection and appear in the pending request count. A full requested window rejects another request instead of silently promising an impossible deadline. Already prepared transitions are retained. Unavailable requested files are reported and skipped. Saved shared playlist sources are not silently rewritten. Deadlines count successful Auto DJ handoffs, not wall time; paused/stopped sessions do not advance them.

Android / AMP Remote / connect to the desktop lets a song be requested in the same 1–5-song window and lets the six desktop techniques be enabled or disabled. The existing desktop password/control permissions apply. The desktop must permit LAN control for another device to reach it; loopback control remains private by default.

Android's local DJ also accepts requests from its song list. It remembers its crossfade time with minus/plus controls, reads prepared cue IN/OUT, and preserves Auto DJ when Auto Crossfade is pressed. Google Cast plays the selected station or desktop live DJ broadcast on the selected speaker and reports connection failures. Audio analysis/separation and reverse-audio scratching are not added to Android; prepared metadata is reused and desktop techniques can be controlled remotely.
