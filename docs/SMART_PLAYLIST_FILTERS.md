# Smart Playlist analysis filters

Library > Smart Playlists now includes Analysis and track filters beside the existing genre selection. Add a field, enter a numeric range, choose text values, or choose Yes/No. Every selected filter must match. Semicolon-separated text choices are OR within that row. Multiple rows, sources and genres are combined with AND. No filters preserves existing behaviour. Numeric and text filters exclude missing values; boolean No can include unanalyzed tracks.

Fields cover BPM and alternative tempo estimates, musical/Camelot key, energy, duration, analysis confidence, analysis/review status, beatgrid, manual edits, cue counts/types/labels and IN/OUT positions, energy-profile sections and labels, analysis engine, and common embedded tags/audio properties. Stem count is explicitly saved metadata entries, not device-local cache readiness. Section labels come from saved preparation; energy analysis does not claim semantic verse/chorus recognition. Manual tag values retain precedence over embedded values.

The shared eligibility function applies these rules to previews, DJ candidates, requests admitted through playlist rules and headless radio. Relaxing recent-song avoidance never relaxes the filters. Filters save with revision-aware Smart Playlist settings, import/export and three-way edits. Filter-bearing settings use rules version 2; their portable exports use version 3, so older readers reject unsupported rules instead of silently omitting the constraints. Existing version-1 settings and earlier exports remain readable. Update other shared-library clients before using filter-bearing rules.

The transition selector is now a separate movable/resizable settings window with switches for scratch, stutter, tape brake, filter sweep, bass swap, beatmatch, loop buildup, stem handoff and vocal/backing mashups. Enabled types rotate at the chosen frequency. Clean blends remain the safe fallback; tempo/grid/stem requirements still apply. Previous single-style choices are converted to equivalent enabled switches when opened.
