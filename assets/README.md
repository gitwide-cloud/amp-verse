# AMP Verse branding

`amp-verse-icon.png` is the original user-supplied A/lightning/V artwork, preserved byte-for-byte without cropping, recoloring or regenerating it.

SHA-256: `181f4038990ede96fe2b8b3c3096a012bd6c2565d18b8288c8edddff1fa963df`

It is embedded in the Player, Library and DJ native window icons and served locally as Cast's browser/touch icon. It requires no external download. Windows Explorer executable resources and installer/launcher icons are separate packaging work; Android branding will be applied when the integrated Android app is built.
